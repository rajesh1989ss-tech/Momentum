MOMENTUM — installable app (PWA)

Put these files online once (GitHub Pages), then install from that link on every device.
1. github.com → New repository → name it "momentum" → Public → Create.
2. "uploading an existing file" → drag in index.html, manifest.webmanifest, sw.js and the icons folder → Commit.
3. Settings → Pages → Source: Deploy from a branch → main / root → Save. Wait a minute.
4. Open https://<your-github-name>.github.io/momentum/ in Chrome.
   Android: menu ⋮ → Install app.   Desktop: install icon at the right of the address bar.
5. In the app: Open import file → Momentum_import_M-0001.json → Apply.

Your tasks are NOT in these files. They stay on each device and arrive only through import files.
To update the app later, replace index.html (and sw.js) in the repository; your data is untouched.
